# Loan Approval EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a loan approval dataset to understand the factors that influence loan approval decisions.

## Objectives
- Analyze applicant demographics
- Study income, loan amount, and credit history
- Identify patterns affecting loan approval

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure
loan-approval-eda/
│
├── data/        → Dataset files  
├── notebooks/   → EDA notebook  
├── images/      → Visualizations  
└── README.md

## Key Insights
- Credit history is the strongest factor for loan approval
- Higher income applicants have better approval rates
- Self-employed applicants show slightly lower approval probability
